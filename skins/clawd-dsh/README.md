# Clawd? 皮肤

玩梗皮肤：有些 AI 中转站拿 DeepSeek 冒充 Claude 卖给用户。于是 Clawd 长出了一条 DeepSeek 的蓝色小尾巴——
尾巴照着 DeepSeek Harness 思考时那个官方动画画的，AI 在思考时也会甩得飞快。

身体、手脚、表情和 Clawd 完全一样，只多了一个 `tail` 部件（像素图 + `pivot` + `sway`），
它可以伸出碰撞盒，所以手感和 Clawd 一模一样。

Clawd 是 Anthropic 旗下 Claude Code 的吉祥物，DeepSeek 是深度求索的产品。这个皮肤是同人作品，与两家都无关，
也不代表官方；相关形象的权利归各自所有者，**不在本项目引擎代码的开源许可范围内**。
